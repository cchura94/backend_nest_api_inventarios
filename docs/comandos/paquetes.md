## Instalación de Swagger

```
npm install --save @nestjs/swagger
```

## Instalación TypeORM (Postgres)

```
npm install @nestjs/typeorm typeorm pg
```
## Instalar dotenv
- Para habilitar el uso de variables de entorno
```
npm install dotenv
```

## Para migraciones instalar:
```
npm install -D ts-node tsconfig-paths
```

### Para Variables de entorno (.env) dotenv
```
npm i --save @nestjs/config
```

### habilitación validación con Class validator
```
npm i --save class-validator class-transformer
```

### cifrado o encriptación de Contraseñas
```
npm i bcrypt
npm i -D @types/bcrypt

```
