## Instalación de Swagger

```
npm install --save @nestjs/swagger
```

## Instalación TypeORM (Postgres)

```
npm install @nestjs/typeorm typeorm pg
```
## Instalar dotenv
- Para habilitar el uso de variables de entorno
```
npm install dotenv
```

## Para migraciones instalar:
```
npm install -D ts-node tsconfig-paths
```
